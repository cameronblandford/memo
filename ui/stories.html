New story

A story is something that you care about for a long time. It is not a memo: it has no state and it never closes. Each Sunday at 9:00, main writes each summary again from your memos and ticks, and it can look at other data on the Mac. Add the tag of a story to a memo in the Inbox to put that memo in the story; main also finds memos with no tag. Write again asks main for a new summary now.
